# Jotter

Mac 上随手记的草稿本，也能当轻量编辑器打开文件和文件夹。

- 在任何应用里按 ⌃⌥空格，叫出一份空白草稿；写了字自动保存，不用起名
- ⌘P 按名字或内容找草稿；打开了文件夹的窗口里先找文件
- JSON、YAML、JSONL、CSV、HTML、Markdown 都能切到预览看；还有一堆处理文本的小工具
- 能把一页钉成便签，浮在所有窗口上面

## 安装

打开「终端」，粘贴这一行回车：

```sh
curl -fsSL https://raw.githubusercontent.com/yct0914/jotter-releases/main/install.sh | sh
```

装好会自动打开。需要 macOS 13 或更新的系统。

以后有新版，Jotter 会弹窗告诉你更新了什么，点「安装并重启」就好；也可以在菜单「Jotter › 检查更新…」手动查。再运行一次上面那行命令也能升级。

## 注意

- 草稿默认 30 天没改过会自动删掉，要长期留的用「另存为文件」；设置（⌘,）里能改天数或改成永不。
- 第一次打开有一页使用说明，以后在「帮助 › 使用说明」里能再看到。
- 不要直接下载安装包双击打开：没有经过苹果检查的应用会被系统拦住。用上面的命令装不会被拦。

更新记录见 [Releases](https://github.com/yct0914/jotter-releases/releases)。
